# Clavier iOS pour Android

Clavier (IME) Android au look et comportement du clavier iPhone : AZERTY/QWERTY, 123 / #+=, aperçu des touches, accents par appui long, majuscules auto + verrouillage (double tap), raccourci « . » (double espace), correction automatique FR/EN, prédictions, balayer pour écrire (QuickPath), trackpad (appui long / glisser sur la barre d'espace), clavier emoji complet (catégories, récents, teintes de peau), dictée vocale, thèmes clair/sombre.

## Installer
1. Onglet **Actions** du dépôt → dernier build « Build APK » → télécharger l'artefact `ios-keyboard-apk`.
2. Installer l'APK sur le téléphone, ouvrir « Clavier iOS », suivre les étapes 1 et 2.

## Emoji style iOS
Le clavier affiche la police emoji du système. Pour les emoji Apple partout (téléphone rooté) : module Magisk/KernelSU https://github.com/n4bi10p/Ios-emoji. Sans root, une police `.ttf` peut être importée dans les réglages (affichage dans le clavier uniquement).
